# 英文口說練習

小朋友的英文口說練習 App（單一網頁）。

- 網站：https://moso8787.github.io/english/
- `index.html`：App 本體
- `bot.gs`：LINE 點數機器人（Google Apps Script）。最上面三行密碼設定是範例文字，真正的設定只存在 Apps Script 裡。
- `math-map.html`：學習大冒險地圖（六科雷達圖、七個世界、寶箱）
- `subjects.html`：學科測驗（數學、國語、自然、社會、學校英語，AI 老師講評）
- `sub-sync.js`：學習大冒險的雲端同步（共用 LINE 點數機器人）
- `worlds/`：地圖和科目徽章圖片
